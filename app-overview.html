Authentication

Register & login with JWT access tokens (stored in memory) and refresh tokens via httpOnly cookies. Automatic token refresh on expiry via Axios interceptors.

Boards

Create, view, and delete personal boards. Each board has a custom color. Dashboard shows all boards in a responsive grid.

Lists

Add, rename, and delete lists within a board. Lists are reorderable via drag-and-drop with float-based positioning to avoid full re-indexes.

Cards

Create and manage cards inside lists. Cards support title, description, due date with color-coded badge, labels (custom text + color), and checklists with multiple items.

Drag & Drop

Powered by @hello-pangea/dnd. Move cards across lists and reorder lists within boards. Optimistic updates with rollback on failure.

Card Modal

Full-detail modal for each card: edit title & description, set due date, manage labels and checklist items inline, delete card.

Testing

Three test suites covering unit, integration, and end-to-end scenarios

⚙️ Server Integration Tests Jest + Supertest
5 suites
📄auth.test.js— Register, login, token refresh, logout flows
📄boards.test.js— CRUD operations on boards with auth checks
📄lists.test.js— List creation, update, delete within boards
📄cards.test.js— Card CRUD, move across lists, due dates
📄middleware.test.js— JWT verification, missing/expired token handling
⚠️ Requires a separate server/.env.test with a different DATABASE_URL. Tests truncate all tables between runs.
⚛️ Client Unit & Component Tests Vitest + RTL
5 suites
📄AuthContext.test.jsx— Auth state provider, login/logout side effects
📄BoardCard.test.jsx— Board card rendering and color display
📄BoardView.test.jsx— Board detail page with lists and drag-and-drop
📄CardModal.test.jsx— Card modal open/close, field editing, labels
📄DueDateBadge.test.jsx— Badge color logic: overdue, due soon, future
🎭 End-to-End Tests Playwright + TypeScript
4 suites
📄auth.spec.ts— Register, login, logout via real browser interactions
📄boards.spec.ts— Create, navigate, and delete boards end-to-end
📄lists-cards.spec.ts— Full list/card lifecycle, drag-and-drop reordering
📄card-detail.spec.ts— Card modal: description, labels, checklists, due date
Run with cd e2e && npx playwright test. Requires both server and client running. E2E tests use a shared test-helpers.ts fixture for user creation and board setup.
